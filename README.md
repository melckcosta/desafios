# Desafios com GitHub Actions

Este repositório contém três desafios práticos para demonstrar o funcionamento do **GitHub Actions**:

- **Desafio 1**: Workflow que leia três variáveis de repositório e exiba no log da execução
- **Desafio 2**: Build e deploy de um projeto Node.js para o Azure App Services
- **Desafio 3**: Criação de Action composite em um repositório apartado e consumi-la pelo workflow

Cada desafio possui seu próprio diretório com instruções específicas.

---

## Como usar

1. Acesse o diretório do desafio desejado.
2. Siga as instruções do `README.md` correspondente.
3. Execute os workflows no GitHub para ver o funcionamento na prática.
